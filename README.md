# Buildspin

Spin a client and a brief to build for them — no timer, just the next thing to ship.

Buildspin is a tiny tool for website/app builders and agencies who want a quick creative prompt: hit spin and get either a client persona (e.g. *a cloud kitchen*, *a coaching institute*) or a project type (e.g. *a booking & appointments app*, *an invoice & billing tool*) to design and build. Filter by industry, copy the result, and go.

- No sign-up, no backend — a single static page
- 140+ personas and 120+ project types across 8 industries
- Installable as a PWA (works offline once loaded)

Open `index.html` directly, or serve the folder to enable install/offline support.
